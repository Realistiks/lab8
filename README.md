## Цель работы

1. Познакомиться с понятием функции, рекурсии и модуля.
2. Научиться объявлять и вызывать функции в Python и C++.
3. Изучить передачу параметров, возврат значений и области видимости.
4. Освоить рекурсивные алгоритмы и создание собственных модулей.
5. Применить полученные знания для модульного программирования.
6. Отработать навыки работы с Git: коммиты, ветвление, push.

## Как запустить

Нужен Python 3.10 и выше. Команды выполняются из папки `Лабы/лаба8`:

```bash
python лаба1.py
python лаба3.py
python лаба4.py
python sr3.py
```

| Программа   | Ввод                                                             | Результат                                      |

| `лаба1.py`  | `17`                                                             | `17 — простое число`                           |
| `лаба2.py`  | `6`                                                              | `6! = 720`                                     |
| `лаба3.py`  | `7.5`, `2.5`                                                     | сумма `10`, частное `3`, среднее `5`           |
